# Security Policy

## Current status

NEXUS is a release candidate, not a verified Windows release. Security findings and build-time dependency limitations are documented in [docs/security.md](docs/security.md). The latest code is the only version currently considered for fixes; no release or patch schedule is promised.

## Report a vulnerability

Please **do not disclose security vulnerabilities, exploit details, private data, or credentials in a public issue or pull request**.

If GitHub's private vulnerability reporting is enabled for this repository, open the repository's **Security** tab and select **Report a vulnerability**. If that option is not available, open an issue without sensitive details to request a private contact method from the maintainer; wait for a private channel before sharing details. Availability of GitHub private reporting depends on repository settings.

Include a description, affected version or commit, reproduction steps, impact, and any relevant sanitized logs once a private channel is available. Never send passwords, tokens, or other secrets. Please give maintainers reasonable time to investigate before public disclosure; response times and remediation timelines are not guaranteed.
